The system / Model → runtime → robot → evidence

The software behind the machine.

I chose Arduino VENTUNO Q for the path from available neural models to an integrated robot.

Arduino App Lab provides model-driven applications and Bricks; Qualcomm AI Hub and Edge Impulse provide routes to model selection, optimisation and deployment. Qwen and Gemma language models, vision-language models, Whisper speech recognition and object detection give the investigation concrete starting points. Each experiment will name its model package, runtime and execution backend.

The integration plan uses ROS 2 Jazzy, a documented base interface and Qualcomm acceleration where the selected board, OS and release support it. The first compute experiment runs on the bench with a recorded workload; the enclosure and drive are introduced as controlled changes. Hardware measurements begin after delivery.
